# Imagens para carrosséis

Biblioteca de imagens fornecida pelo mantenedor para compor fundos de carrosséis no Carousel Studio.

| Pasta | Arquivos | Tema |
| --- | ---: | --- |
| `xamanismo/` | 74 | Xamanismo |
| `terapias/` | 100 | Terapias |

Todos os arquivos são WebP de 800 × 540 px. Como os slides costumam ser verticais, ajuste posição, zoom e opacidade no painel **Imagem de fundo** após escolher uma imagem. O editor incorpora a imagem escolhida ao carrossel, que continua funcionando offline.

Para usar: abra o `carrossel-editor.html`, selecione um slide e, em **Imagem de fundo**, envie o WebP desta pasta. Ao gerar um editor já preenchido, coloque a imagem como URI de dados no campo `bg_uri` do slide; um caminho local ou link do Google Drive não garante que o HTML funcione offline.

Origem: [pasta “Imagens para uso” no Google Drive](https://drive.google.com/drive/folders/1HVUQbV3OE9BXwuE0CAhlj6iRRthDm223). A pasta `Despertar` estava vazia na importação de 27/10/2026.

As imagens foram disponibilizadas para uso em carrosséis com este plugin. A licença MIT do código não define uma licença separada para redistribuir as imagens avulsas.
