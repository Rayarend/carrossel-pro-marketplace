# Referência de carrosséis do Xamã

[`divorcioSKILL.md`](divorcioSKILL.md) é a skill original fornecida por Ray Arend para carrosséis do perfil `@xama.pena.azul.do.amor`. Foi preservada como referência de marca, sem ativação automática no plugin geral.

Ela pode orientar carrosséis dessa marca em quatro pontos:

- Paleta de preto, azul `#0F5A88`, laranja `#F4A61C` e branco.
- Tipografia de impacto na capa e texto narrativo nos slides internos.
- Temas e voz voltados a encerramento de ciclos e libertação emocional.
- Assinatura visual com avatar, nome e barra dourada/azul.

O fluxo técnico do arquivo original é anterior ao Carousel Studio: propõe HTML próprio ou PNG por Python/PIL. Para um carrossel novo com o plugin atual, use essas diretrizes de marca no editor padrão. Os três arquivos citados em `assets/` no original não acompanharam o documento e precisam ser fornecidos antes de reproduzir o avatar e os modelos aprovados.
